Expected CSV Format

Long format — one row per vibration sample. Column names are case-insensitive.

ColumnRequiredDescription
sensor_idRequiredUnique ID per sensor (e.g. S01)
chainage_kmRequiredSensor position along the route, km
acceleration_gRequiredAccelerometer reading, in g
sample_indexOptionalSample order (defaults to row order)
sampling_rate_hzOptionalSensor sampling rate (default 1000 Hz)
speed_limit_kmphOptionalPosted speed limit for that segment
sensor_nameOptionalDisplay name for the sensor

Each sensor needs at least 32 samples for a usable FFT. RailPulse scores condition using energy concentrated in known corrugation, wheel-flat, joint-gap and rail-crack frequency bands — treat results as a heuristic screening pass, not a certified inspection.
